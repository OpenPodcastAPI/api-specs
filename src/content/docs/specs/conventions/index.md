The following conventions are used for all endpoints in the Open Podcast API specification:
* Core and optional functionality
* Synchronization model
  * Client behavior
  * Server behavior
* Client IDs
* Timestamps & modifications
* Requests
  * Content type
* Responses
  * Response codes
  * Pagination
